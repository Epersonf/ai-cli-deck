# ai-cli-deck

Local web app that gives native AI coding CLIs (claude, codex, ...) a unified browser interface:
real CLI processes in a pty streamed with xterm.js, plus a file explorer, a per-session preview
and an MCP server so agents can talk back to the app.

Target runtime: Termux > Ubuntu (proot-distro) on Android, opened in the phone browser.

Status: planning. See [docs/project-brief.md](docs/project-brief.md) for the full brief and milestones.
